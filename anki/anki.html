Exportar

Cartões: conteúdo + agendamento, sem histórico. Backup completo: cartões + todo o histórico de revisões (use este para segurança).

Importar

JSON (backup deste sistema, inclusive os antigos) ou CSV (colunas: frente;verso;assunto;subtopico — o assunto pode ser um caminho “A > B > C”; cria cartões e assuntos novos). Nada é gravado antes de você confirmar a prévia; cartões existentes nunca são sobrescritos sem escolha explícita.

Preferências (neste aparelho)

Novo cartão

Separe os níveis com “>”. Se preencher, o caminho é criado (ou reaproveitado) e vale no lugar da lista. Para organizar a estrutura toda, use a página Assuntos.

Formatação: **negrito**, *itálico*, `código`. Quebras de linha são preservadas. HTML não é interpretado.
